# ab-compare: 설정 하나만 바꾼 렌더 비교

같은 컷을 같은 시드와 프롬프트로, 설정 **하나만** 바꿔 렌더한 결과들을 비교합니다. 예를 들어 LoRA 끄기·바꾸기, 리얼리즘 LoRA 추가, 프롬프트 한 줄 변경 같은 경우입니다.

- `frames`: 모든 칸에서 같은 시각의 프레임을 뽑고 세 가지를 만듭니다.
  - **빛 수치:** 하얗게 날아간 픽셀(`blown`, 밝기 240 초과)과 번진 픽셀(`glow`, 200~240)의 비율입니다. 원하면 비전 모델에 "빛이 번지는가"를 예/아니오 확률로도 묻습니다(`--vlm`).
  - **블라인드 페이지:** 칸 이름을 A/B/C로 가린 비교 화면입니다(`blind.html`). 사람이 줄마다 가장 좋은 것을 고르고 `votes.csv`로 내보냅니다.
- `reveal`: 가린 글자를 원래 칸 이름으로 되돌리고, 표를 숫자와 함께 정리합니다(`RESULT.md`).

필요한 것: ffmpeg, Pillow. 비전 확인에는 `chat-upgrade/chatup`을 씁니다.

`blown`과 `glow`는 화면이 전체적으로 어두워져도 내려갑니다. 그래서 평균 밝기(`luma`)와 사람 판정을 함께 봅니다. 렌더 결과와 프레임은 올리지 않습니다.

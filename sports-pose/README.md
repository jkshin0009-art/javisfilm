# sports-pose: 스포츠 교본 자세 자산

스포츠 교본과 생체역학 논문의 자세를 **이미지 생성과 영화 제작에 바로 쓰는 자산**으로 만든 폴더입니다. 목적은 프롬프트 에이전트가 동작을 지어내지 않고 자산을 따라 쓰게 해서, 인체 뼈대 왜곡(찐빠)을 줄이는 것입니다.

자산 하나는 관절 각도로 정의한 **3D 뼈대 한 개**입니다. 이 뼈대에서 다음 네 가지가 모두 나옵니다. 그래서 글과 그림이 서로 어긋나지 않습니다.

| 파일 | 내용 | 쓰는 곳 |
|---|---|---|
| `prompt.md` | 5단 영문 자산(SYSTEM_INDEX_CODE, ANATOMICAL_BONES, OBJECT_INTERACTION, CINEMATIC_CAMERA, KINETIC_ENERGY), 바로 쓰는 프롬프트, negative, 규칙 표, 출처 | 프롬프트 에이전트 |
| `openpose_<카메라>.png` | ControlNet OpenPose 이미지(몸 18점 + 손 21점×2). 카메라마다 한 장 | ComfyUI |
| `openpose_<카메라>.json` | 같은 점의 OpenPose JSON, 픽셀 좌표 | ComfyUI, OpenPose 편집기 |
| `preview.png`, `skeleton3d.json` | 세 방향 뼈대 그림(공·네트·림·배트·라켓·낚싯대·마운드·스타트대·수면 포함)과 3D 좌표 | 사람 확인, 3D 도구 |

`prompt.md`에는 **공식 경기 규칙 표**도 들어 있습니다. 그 동작에 걸리는 조항의 번호와 내용, 그리고 이 뼈대에서 잰 검사 결과입니다(예: `FIVB 11.3.1 네트 접촉: OK, 네트까지 4 cm`).

프롬프트 에이전트가 따를 절차는 **[AGENT_GUIDE.md](AGENT_GUIDE.md)** 에 있습니다. 자산 목록은 `library/CATALOG.md`에 있습니다.

- OpenPose 이미지와 JSON에 두 사람이 모두 들어 있습니다.
- 프롬프트에는 `{PARTNER_B}` 자리가 하나 더 있습니다. 상대 선수의 외모를 넣습니다.

## 명령

```
python sportspose.py build                  모든 자산 검사 후 library/ 다시 만들기 (약 2분)
python sportspose.py build VOLLEYBALL_BLOCK 하나만
python sportspose.py check                  검사만
python sportspose.py find "배구 스파이크"      찾기 (한국어/영어)
python sportspose.py show SOCCER_SIDE_VOLLEY 5단 블록과 프롬프트 출력
python sportspose.py sequence BASEBALL_PITCH 한 동작의 단계를 순서대로 (영상용)
python sportspose.py rules volleyball       종목의 공식 규칙 요약 (치수, 장면, 반칙)
python fetch_refs.py -n 4                   참고 사진 받기 (위키미디어 공용, PC에서)
python -m pytest -q tests                   테스트 48개 (약 6분)
```

필요한 것은 Python 3.9 이상과 Pillow입니다. numpy는 쓰지 않습니다.

## 검사 항목

`build`는 아래를 모두 통과해야 `ok`를 냅니다.

- **관절 가동 범위:** 정상 가동 범위(AAOS 등)를 선수 수준으로 넓힌 한계입니다.
  - 불가능한 각도는 오류, 드문 각도는 경고로 표시합니다.
  - 예: 팔꿈치가 반대로 꺾임, 어깨 뒤로 90° 이상 들어 올림.
- **접지:** 딛고 있다고 한 발이 바닥에 닿는지, 몸이나 공이 바닥 아래로 들어가지 않는지 봅니다. 투구는 마운드 경사를, 수영 스타트는 스타트대 높이와 경사를 따릅니다.
  - 무릎 꿇기(레슬링 태클), 누운 자세(유도 착지)는 정강이 앞, 등, 엉치처럼 실제로 매트에 닿는 몸 표면으로 검사합니다.
  - 수영은 물에 뜬 높이로 정하고, 글 속 높이도 수면 기준(예: "수면 아래 0.25 m")으로 씁니다.
- **두 사람:** 상대 선수와 몸통·머리·허벅지·위팔이 4 cm 넘게 파고들면 오류입니다. 손과 아래팔은 잡기 위해 닿을 수 있습니다.
- **접촉:** 손이나 발이 공, 배트, 목표 지점에 닿았는지 봅니다. IK로 푼 결과가 3 cm 안에 들어와야 합니다.
- **자세 규칙:** 자산마다 논문과 교본에서 가져온 각도·거리 범위이고, 출처를 붙였습니다.
  - 예: 투구 착지 때 팔꿈치 80~115°, 스파이크 타점에서 공이 어깨 앞 5~45 cm.
- **공식 경기 규칙:** `rules/<종목>.json`에 12종목 규칙서(FIVB, IFAB, MLB, FIBA, ITF, BWF, IGFA, World Boxing, WT, World Aquatics, IJF, UWW)의 조항과 함께 들어 있습니다. 반칙 장면이 나오면 그 종목을 아는 관객에게 바로 티가 나기 때문입니다.
  - **치수와 용구:** 네트·림 높이, 공 크기, 마운드처럼 자산에 나오는 것이 규격과 맞는지 검사합니다.
  - **반칙:** 뼈대로 잴 수 있는 것은 검사합니다. 나머지는 글로 넣고, 반칙 모습은 negative에 추가합니다. 검사하는 반칙의 예:
    - 구기: 네트 접촉, 센터라인, 상대 쪽에서 때린 공격, 필드 선수 팔에 닿은 공, 골키퍼의 페널티 에어리어 밖 처리, 투수판에서 뗀 축발, 타석 밖의 발, 상대를 보지 않는 수비
    - 라켓: 테니스 풋 폴트, 배드민턴 서브 높이(1.15 m)와 두 발 접지
    - 격투: 권투 벨트 아래 가격과 편 주먹, 태권도 몸통 보호대 밖 발차기·허리 아래 공격·얼굴 주먹, 유도 다리 잡기·얼굴 누르기·머리 박기, 그레코로만 허리 아래 잡기
    - 수영: 스타트대 앞 끝의 발, 평영 팔꿈치 수면 아래, 접영·평영 좌우 동시 동작
    - 낚시: 낚시꾼 혼자 낚싯대를 잡음, 낚싯대 끝·손잡이 길이(IGFA)
  - **장면:** 인원 수, 유니폼, 심판 위치는 여러 명이 나오는 장면을 위해 `prompt.md`와 `rules` 명령에 적어 둡니다.

## 자산 JSON (`assets/<종목>/<코드>.json`)

좌표와 각도 규칙:

- **좌표:** x는 경기 진행 방향(네트, 골대, 홈플레이트, 림 쪽), y는 그 왼쪽, z는 위쪽입니다. 단위는 m, 바닥은 z=0입니다.
- **팔:**
  - `elev`: 0 = 내림, 90 = 수평, 180 = 머리 위
  - `plane`: 0 = 옆, 90 = 앞, 음수 = 몸 뒤
  - `rot`: + = 외회전
  - `elbow`: 굴곡 각도, 0 = 폄
  - `pron`: + = 엎침
  - `wrist`: + = 손바닥 쪽 굽힘
  - `hand`: 손가락 모양 (`flat`, `spread`, `cupped`, `ball_hold`, `grip`, `fist`, `platform`)
- **다리:**
  - `flex`: 엉덩관절 굴곡 (- = 폄)
  - `abd`: 외전
  - `rot`: + = 외회전
  - `knee`: 무릎 굴곡
  - `ankle`: + = 발끝 내림. `"flat"`이면 발바닥 수평, `"toes:30"`이면 뒤꿈치를 30° 든 상태
- **몸통, 골반, 머리:**
  - `flex`: + = 앞으로
  - `side`: + = 오른쪽으로 기울임
  - `rot`: + = 왼쪽으로 돌림
  - 골반 `tilt`: + = 앞으로 숙임 (90 = 엎드림, -90 = 누움), `roll`: 몸의 긴 축을 따라 굴림 (수영 호흡)
  - `look_at`: 머리가 공이나 림을 보게 합니다
- **손과 발 IK:** `"reach": {"to": "ball"}`이면 손바닥(다리는 발등, 발바닥, 발목, 발끝)을 공 표면이나 지점에 정확히 놓습니다.
  - `side`: 공의 어느 면에 닿을지
  - `face`: 손바닥이 향할 방향
  - `range`: 풀이 범위
  - `offset_m`: 목표점에서 조금 떨어진 곳 (예: 턱 아래 12 cm)
  - `"B.l_lapel"`처럼 `B.`를 붙이면 상대 선수의 몸 부위입니다. 깃(`lapel`), 소매(`sleeve`, `upper_sleeve`), 벨트(`belt_front`, `belt_back`), 턱, 가드 위치(`guard`), 무릎 뒤 등이 있습니다.
- **지지:** 둘 중 하나로 정합니다.
  - `"support": {"contacts": ["l_foot"]}`: 바닥에 닿는 부위
  - `{"airborne_m": 0.55}`: 공중에 뜬 높이
  - 긴 스트라이드처럼 두 발 위치를 먼저 정할 때는 `{"pelvis_z_m": "auto"}`와 발 IK를 함께 씁니다.
  - `{"float": {"point": "sacrum", "depth_m": 0.0}}`: 수영. 그 몸 부위가 수면(`water_m`)에서 그 깊이에 있습니다.
  - `"contacts": ["back_upper", "sacrum"]`: 누운 자세. 발 대신 몸 표면이 매트에 닿습니다.
- **상대 선수:** `partners`에 `{"id": "B", "role": ..., "pose": ..., "support": {"root_from": "A.pelvis", "root_offset": [x, y], ...}}`를 넣습니다. B의 자세도 같은 방식으로 쓰고, B의 손이 A를 잡을 때는 `"A.r_sleeve"`처럼 씁니다.
- **바닥:** `ground`로 마운드(`mound`), 수영장(`pool`), 스타트대(`block`)를 정합니다.
- **글 속 수치:** 글 속 `{fwd:ball:r_shoulder}` 같은 자리는 뼈대에서 잰 값(cm)으로 바뀝니다.

## 자산 추가

1. 비슷한 자산 JSON을 복사해 코드, 이름(한국어·영어), 각도를 고칩니다.
2. 교본·논문 수치를 `rules`에 넣고 `sources`에 출처를 적습니다.
3. `python sportspose.py build <코드>`를 실행해 오류가 없을 때까지 각도를 고칩니다.
4. `preview.png`를 눈으로 봅니다. 규칙을 통과해도 어색하면 각도를 다시 봅니다.
5. `python sportspose.py build`로 전체를 다시 만들어 index와 카탈로그를 갱신합니다.

## 참고 사진

`fetch_refs.py`는 자산마다 위키미디어 공용에서 사진을 찾아 `refs/`에 받습니다.

- 받는 라이선스는 퍼블릭 도메인, CC0, CC BY, CC BY-SA뿐입니다. NC(비영리)나 ND(변경 금지)는 받지 않습니다.
- 엔딩 크레딧용 저작자 표시를 `refs/ATTRIBUTION.md`에 씁니다.
- `refs/`는 저장소에 올리지 않습니다(`.gitignore`).
- 이 자산을 만든 클라우드 환경은 위키미디어 접속이 막혀 있어서 사진을 받지 못했습니다. 사진은 PC에서 받습니다.

## 한계 (정직하게)

- **수치의 출처:** 조사 환경에서 논문 원문 사이트가 막혀서, 수치는 대부분 검색 결과에 나온 논문 초록·발췌에서 가져왔습니다.
  - 각 규칙에 출처를 달았으니, 정밀한 용도라면 원문과 대조하세요.
  - 야구 수치는 Driveline OpenBiomechanics 실측 데이터(투수 100명, 타자 98명)의 평균입니다. 이 데이터는 CC BY-NC-SA 4.0이라 평균값만 쓰고 원본 데이터는 넣지 않았습니다.
- **골키퍼·헤딩·레이업·덩크:** 논문 각도가 부족해서 교본 설명을 바탕으로 추정한 값을 썼고, 규칙에 "estimate"라고 표시했습니다.
- **새 8종목(테니스~레슬링):**
  - 자세 수치는 대부분 교본 설명을 바탕으로 한 추정값(`EST`)입니다. 테니스·배드민턴은 일부 논문 발췌가 있습니다.
  - 공식 규칙서 사이트는 조사 환경에서 모두 막혀 있었습니다.
    - 테니스·배드민턴: 검색 발췌와 규칙서 사본을 썼습니다.
    - 유도·레슬링: 2차 요약본을 썼습니다.
    - 낚시·권투·태권도·수영: 일반 지식으로 썼습니다.
    - 각 `rules/<종목>.json`의 `text_used`에 출처를 적어 두었습니다. 조항 번호와 점수, 벌칙 단계는 현재 판과 대조하세요.
  - 유도 굳히기(곁누르기)는 두 몸이 서로 파고들지 않는 자세를 만들지 못해 넣지 않았습니다. 대신 한판 착지(낙법)를 넣었습니다.
  - 잡기 자세에서 손바닥은 상대 팔의 중심선에서 최대 8 cm까지 떨어져 있어도 통과합니다. 팔 두께만큼입니다.
- **좌우:** 모두 오른손·오른발잡이 기준입니다. 좌우 반전 기능은 아직 없습니다.
- **몸 모델:** 신체 비율은 한 가지(Drillis & Contini)이고, 척추는 한 마디, 손가락은 모양 몇 가지입니다. 체형 차이나 미세한 손가락 자세는 표현하지 못합니다.
- **완벽함은 보장하지 않습니다:** 자세 이미지와 정확한 글로 왜곡을 크게 줄일 수는 있지만 없앨 수는 없습니다. 특히 손은 여전히 가장 약한 부분이라 결과 확인이 필요합니다.
